# Study in the Philippines

A responsive Next.js App Router website for exploring study options, university profiles, student life and practical information about the Philippines.

## Built with

- Next.js App Router
- JavaScript and JSX
- React
- Tailwind CSS
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before publishing

University entries are illustrative examples, not verified institutions. Replace them with researched and approved information before publishing. Confirm admission requirements, fees, programme recognition, medical education guidance, immigration requirements and other regulatory information against current official sources. Include the source and the date it was checked.

The contact form and informational directory require a connected service or verified content before they can be used as production services.
